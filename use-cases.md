# Прецеденти використання (Use Cases)

## 1. Опис Use Cases

* **UC-1: Аутентифікація** — Вхід та реєстрація користувачів у системі.
* **UC-2: Бронювання заняття** — Вибір вільного слоту та створення запису про заняття.
* **UC-3: Перевірка доступності слоту** — Внутрішня перевірка відсутності накладок у розкладі.
* **UC-4: Обробка оплати** — Взаємодія з платіжним сервісом для підтвердження транзакції.
* **UC-5: Налаштування розкладу** — Додавання та редагування вільних слотів репетитором.
