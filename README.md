# Онлайн-платформа бронювання репетиторських занять (TutorBooking)

## Опис проєкту
Платформа призначена для автоматизації процесів пошуку, підбору та бронювання індивідуальних занять між учнями та репетиторами з різних предметів.

## Проблема, яку вирішує система
* **Для учнів:** складність пошуку репетиторів з різних предметів в одному місці та відсутність зручного інструменту для узгодження розкладу.
* **Для репетиторів:** високі затрати часу на пошук нових учнів та хаотичне ведення графіка занять.

## Основний функціонал
* **Керування профілями та предметами:**
  * Створення профілів користувачів із поділом на ролі (*Учень*, *Репетитор*).
  * Формування профілю репетитора (опис, предмети, вартість за годину).
* **Пошук та підбір:**
  * Пошук репетиторів за предметами та фільтрація.
  * Можливість для учня навчатися у кількох репетиторів одночасно.
  * Можливість для репетитора набирати та вести декількох учнів.
* **Розклад та бронювання:**
  * Формування графіку доступності репетитора.
  * Бронювання занять учнями на вільні часові слоти.
  * Відстеження статусів занять (*Заплановано*, *Завершено*, *Скасовано*).
