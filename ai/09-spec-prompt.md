# Промпт #9: Формування специфікації динаміки сценарію (spec.md)

## Запит користувача
Описати текстову специфікацію динаміки для ключового Use Case із Завдання 2 (UC-2: Бронювання заняття + UC-4: Обробка оплати). Визначити всіх учасників (компоненти, сервіси та базу даних з урахуванням ER-моделі із Завдання 1) та розписати покроковий перелік дій для основного (Main Flow) та двох альтернативних потоків (Alternative Flows).
