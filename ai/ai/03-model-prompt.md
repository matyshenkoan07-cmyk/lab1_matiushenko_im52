# Промпт #3: Генерація початкової ER-моделі (Mermaid)

## Запит користувача
Згенерувати ER-діаграму у синтаксисі Mermaid erDiagram на основі специфікації spec.md для платформи бронювання репетиторських занять.

## Результат генерації AI
Згенеровано першу версію ER-діаграми у файлі `model.md`.

## Знайдені розбіжності під час аудиту (для виправлення):
1. **Кардинальність User ↔ TutorProfile:** Вказано 1:N замість 1:1.
2. **Відсутній ключ subject_id FK:** У сутності `LESSON` немає ключа предмета та зв'язку з `SUBJECT`.
3. **Неявні зв'язки в LESSON:** Ролі учня та репетитора об'єднані в один зв'язок `participates`.
