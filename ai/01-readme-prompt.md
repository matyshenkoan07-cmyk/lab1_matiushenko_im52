## Запит користувача
Назва: Онлайн-платформа бронювання репетиторських занять 
Проблема яку вирішує: вирішує проблему пошуку репетитора для учнів і також проблему пошуку учнів для репетиторів.
Основний функціонал: пошук репетитора або учня, вибір предмету який хочеш підтягнути, створення власного графіку занять для учнів та репетиторів, для репетитора можливість брати кількох учнів, для учня можливість брати декілька репетиторів з різних предметів.
