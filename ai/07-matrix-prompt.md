# Промпт #7: Генерація Use Case діаграми та Матриці трасування M:N

## Запит користувача
Розробити Use Case діаграму у синтаксисі Mermaid з узагальненням акторів (User), зв'язками <<include>> та <<extend>>, а також сформувати Матрицю трасування M:N між EARS-вимогами, Use Cases та Gherkin-сценаріями із зазначенням непокритої вимоги.
