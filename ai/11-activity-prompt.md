# Промпт для генерації Activity-діаграми (11-activity-prompt.md)

## Контекст та Мета
Потрібно побудувати Activity-діаграму (Mermaid flowchart `graph TD`) для бізнес-процесу бронювання та оплати занять (`UC-2` + `UC-4`) на основі затвердженого `spec.md`.

## Вимоги до діаграми:
1. **Swimlanes (subgraphs):** Відобразити 5 учасників: `Student`, `ClientUI`, `BookingService`, `PaymentService`, `Database`.
2. **Розгалуження (Decision Nodes):**
   - Перевірка наявності слоту (*Слот вільний?*).
   - Перевірка результату оплати (*Оплата успішна?*).
3. **Паралельність (Fork / Join):** При успішній оплаті запаралелити оновлення статусу в БД (`Confirmed`) та надсилання Push/Email сповіщення учню.
4. **Повідомлення (Message Event):** Показати надсилання Webhook callback від `PaymentService` до `BookingService` та реакцію системи при відмові (зміна статусу на `Available`).
5. **Синхронізація:** Назви методів у camelCase, підписи українською мовою.

Згенеруй Mermaid-код діаграми для файлу `activity.md`.
